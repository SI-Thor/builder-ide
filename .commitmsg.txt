docs and the honest numbers: the README, the model, the prior art, the
seed method, the language fit, and the desk.sh proposal

This commit is the documentation set, plus three corrections the seeded
history forced.

The docs

- README.md: the program in Casey's terms — the carpet example, the bid, the
  award, the stop rule, the close, the debt and the retooling — with the
  numbers the seeded history actually produces.
- docs/model.md: the entities and every formula (the factor, the
  shrinkage, the confidence, the award score, the overrun, the penalty, the
  debt, the repayment, the stop rule), what is measured, what is estimated,
  what is unknown, and what is not verified.
- docs/prior-art.md: what crab-cell, nursery-v2, cuda-contract, flux-market,
  cuda-budget, trust-ledger, decision-ledger and ledger-continuity already
  had, what is taken from each (with credit), and what each one is still
  missing. AI-Writings and builder-ide are not reachable from the Thor, so
  the document says so instead of pretending to have read them.
- docs/seed-method.md: how the 50 lanes were rebuilt from the board
  history, the seat output files and the queue; the three judgement calls;
  and how to rebuild it.
- docs/design/language-fit.md: why Rust, std only, for the ledger and the
  program, and Python for the reconstruction script.
- docs/integration.md: the three-line change to desk.sh that appends the
  contract block to a seat's brief. Proposed only — desk.sh is not edited
  here.

The three corrections

1. Lateness was being invented. The seeded lanes all read "on time 100%",
   because their close rows carried late_days 0 and the report treated a
   zero as a measurement. No historical lane had a recorded deadline, so
   lateness is unknown for all of them. The seeded jobs now carry no
   deadline, the on-time column reads n/a where no deadline was recorded,
   and the reputation drops a component it could not measure instead of
   scoring it as perfect. A seat that never promised anything gets no debt
   either: with no promise in force there is no overrun, no penalty and no
   lateness.

2. A change order now moves the allowance as well as the promise. Extending
   a job that does not raise the crew-time ceiling leaves the seat over
   budget by definition.

3. The seeded closes record their measurement method as the plain word
   "wall", with the detail in a note, so the report's measurement census
   counts them instead of filing all 50 as "estimated".

Also: the credit for a pi seat's token counts is a plain note; the examples
demo now submits two bids so the award has a real choice, and its burn
really crosses 80% so the stop rule really fires.
