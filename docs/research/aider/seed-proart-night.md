# Seed-2.0-mini: night jobs for the idle ProArt (2026-11-01, /ask)

► ANSWER                                                                        

Your idle overnight ProArt (RTX 4050, Radeon iGPU, WSL) can run six targeted,   
low-lift jobs to supercharge the Thor’s next-day work, each with a clear,       
measurable success metric:                                                      

 1 Preview thumbnail pre-caching: Render compressed glTF/USD thumbnails for     
   every overnight Thor-generated world build, asset, and render, stored locally
   for fast access. Morning metric: Percentage of day-one user preview requests 
   loading in under 1 second, cutting visible wait times.                       
 2 Quantized vision critic shadow runs: Run a lightweight quantized V-JEPA 2    
   locally to flag obvious flaws (blurry textures, misaligned props) in         
   overnight Thor renders before the cloud critic processes them, trimming      
   unnecessary cloud spend. Morning metric: Share of low-quality overnight      
   renders skipped by the cloud pipeline.                                       
 3 Syzygy text view pre-compilation: Pre-generate deterministic,                
   viewpoint-aligned Syzygy text projections for all active overnight builder   
   sessions, caching compact text outputs. Morning metric: Time to first loaded 
   Syzygy frame for morning user logins.                                        
 4 Overnight voice query pre-processing: Use your built-in LFM3-Audio-2B model  
   to transcribe late-night user voice notes, draft context-aware short replies 
   tied to the day’s planned work orders, and store them in the Thor’s shared   
   context packet. Morning metric: Share of morning voice queries answered      
   without cloud LLM wait time.                                                 
 5 Local tile library indexing: Sort and tag all new cloud-generated tiles      
   (props, motion clips, recipe snippets) overnight, building a fast local      
   search index tied to the Thor’s official vocabulary. Morning metric: Average 
   time to locate a requested asset tile for a new work order.                  
 6 Presence scheduler fine-tuning: Analyze the Thor’s overnight resource logs to
   adjust the low-priority study/practice queue, filling idle GPU cycles without
   disrupting morning live work. Morning metric: Share of Thor’s unused         
   overnight compute cycles fully utilized.
